# Multiplayer

Nightingale supports local multiplayer for two to four singers. Each singer uses a separate microphone and can sing as a saved profile or as a guest.

## Requirements

- At least two connected microphones
- One different microphone per singer
- Two to four players
- Saved profiles are optional

Browser-based playback also needs microphone permission for every device Nightingale uses.

## Starting Multiplayer

For one song, open its details sidebar and select the people button beside **Play**. For a set list, open **Playback Queue** and select the people button beside **Play Queue**.

In **Set up players**:

1. Choose a saved profile or **Guest** for each singer.
2. Assign a connected microphone to each singer.
3. Add up to four players or remove extra rows.
4. Select **Start multiplayer**.

Each saved profile and microphone can only be used once in a lineup. Nightingale remembers the last valid lineup on that device for the next multiplayer session.

## During Playback

Each singer has a color-coded live score. Keyboard and gamepad navigation work as they do elsewhere in Nightingale.

The solo `M` and `N` shortcuts are disabled during multiplayer because microphones are assigned before playback. To change assignments, return to player setup.

## Queue Playback

When multiplayer starts from the playback queue, the lineup stays active for every queued song. At the results screen:

- **Next Song** keeps the current lineup.
- **Change players** opens player setup before the next song.
- The exit button returns to the menu.

Songs can be reordered or removed from the queue before playback. See [Keyboard & Gamepad](./controls-reference.md#playback-queue-and-session-mode) for queue controls.

## Results and Profiles

Results are ranked from highest score to lowest. Scores assigned to saved profiles are added to those profiles' per-song scoreboards. Guest scores appear in the current results but are not saved.

See [Pitch Scoring](./scoring.md) for calibration and scoring details, and [Profiles](./profiles.md) for stored score behavior.
